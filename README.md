# AZ GPS PRO

مكتبة iOS مستقلة لتجارب الموقع داخل تطبيقك التجريبي، بواجهة عائمة مختصرة.

## الوظائف الحالية
- اختيار الموقع على الخريطة والبحث وتثبيت موقع محاكى.
- قراءة الموقع الحقيقي، الانتقال إليه واستعادة الموقع الأصلي.
- حفظ المواقع واختيار موقع محفوظ لتفعيله.
- اعتراض identifierForVendor داخل عملية التطبيق، وتوليده أو إدخاله أو استعادته.
- سجل للأحداث والاعتراضات.

## البناء
من GitHub Actions اختر **Build AZ.GPS.PRO** ثم **Run workflow**.
حمّل **AZ.GPS.PRO-arm64-ios12** وفك الضغط للحصول على **AZ.GPS.PRO.dylib** و**SHA256SUMS.txt**.
حمّل مكتبة واحدة داخل تطبيقك التجريبي ثم أعد توقيع التطبيق كاملًا بأداة التوقيع المعتادة.

للبناء محليًا على macOS مع Xcode:
```sh
make test
make
```

## تنظيم الملفات
| المسار | المسؤولية |
|---|---|
| src/Location | إدارة الموقع الحقيقي والمحاكى الثابت والمحفوظات والاعتراضات |
| src/UI | الواجهة العائمة والخريطة |
| src/Identity | اعتراض معرف IDFV وإدارته |
| src/Audit | تسجيل الأحداث وعرض السجل |
| src/Shared | دوال C++ المشتركة القابلة للاختبار |
| tests | اختبارات الدوال المشتركة |
| docs | المعمارية والتحقق ومصدر النسخة |
| .github/workflows | البناء والاختبار وإنتاج المكتبة |

## التوافق والحالة
هدف البناء **iOS 12+ / arm64**؛ لا يعني ذلك اختبار جميع إصدارات iOS.
المعرف المعدّل هو IDFV داخل التطبيق؛ لا يغير معرف الجهاز على مستوى النظام.
انظر [خطة التحقق](docs/TESTING.md) و[مصدر النسخة](docs/BASELINE.md).
