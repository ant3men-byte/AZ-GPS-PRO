# التحقق
## GitHub Actions
make test يشغل اختبارات C++ المشتركة.
make يبني مكتبة iOS ويوقعها توقيعًا ad-hoc.
الـ workflow يتحقق من arm64، يعرض الربط، يتحقق من التوقيع ويولد SHA256SUMS.txt.

## قبول الجهاز
- قارن الموقع أثناء تعطيل المحاكاة بالموقع الحقيقي.
- اختبر التثبيت وتغيير الإحداثيات والاستعادة وموقعي مع السماح بالموقع.
- احفظ موقعين واختر كلًا منهما من المحفوظات.
- اختبر معاينة المسار وتشغيله وإيقافه واستئنافه، ثم الانتقال للعشوائي والاستعادة.
- اختبر الجدولة أثناء نشاط التطبيق وبعد إعادة فتحه؛ التعليق لا يضمن التنفيذ.
- اختبر IDFV قبل التغيير وبعده وعقب الاستعادة بقراءة جديدة داخل التطبيق.
- اختبر أحجام الأزرار وإخفاءها وإعادة فتح الواجهة وإعادة ضبط التخصيص.
- اختبر لمس التطبيق خارج الواجهة وتوقيع التطبيق بعد إدراج المكتبة.

نجاح اختبارات C++ وحده لا يثبت سلامة اعتراضات Objective-C أو واجهة الجهاز.
يلزم نجاح بناء هذه النسخة المنظمة وإعادة اختبارها على الجهاز.
