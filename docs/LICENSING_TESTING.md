# اختبارات الترخيص

## آلية
`node --test backend/tests/*.test.mjs`: إثبات تثبيت صحيح وخاطئ، nonce معدّل، DER غير صالح، توقيع استجابة صحيح ومعدّل، انتهاء الإذن عند انتهاء الاشتراك، HMAC، رفض الإدارة دون token، وتعطيل API غير المعد.

Licensing backend tests في GitHub يطبق schema على PostgreSQL 16 ثم يشغل database.sql داخل transaction يتراجع عنها: كود غير مستخدم، أول تفعيل، التثبيت نفسه، تجاوز عدد الأجهزة، تطبيق مختلف، challenge معاد، تمديد مع حفظ activated_at، إيقاف وإعادة تفعيل، نقل وإعادة ربط وحدود النقل، انتهاء وتمديد منتهي وإلغاء نهائي، وصلاحيات anon.

Build AZ.GPS.PRO يشغل الاختبارات المشتركة ويبني arm64/iOS12 ويتحقق من توقيع الديلوب.

## قبول جهاز فعلي مع سيرفر تجريبي
1. أول فتح يعرض نافذة الكود فقط ولا يغير الموقع أو IDFV.
2. كود خاطئ لا يعطل التطبيق ويمكن إغلاق النافذة.
3. كود صالح يفتح الوظائف بعد التحقق لكن يبقي GPS UI مخفية؛ ثلاث نقرات متتالية على الشاشة تظهرها.
4. أغلق التطبيق وأعد فتحه: تحقق جديد دون إعادة إدخال كود، وواجهة GPS مخفية.
5. افصل الشبكة قبل الفتح: الوظائف OFF والتطبيق طبيعي. أعد الاتصال: تحقق تلقائي.
6. افصل الشبكة بعد التفعيل: path failure يعطل الوظائف؛ Wi-Fi بلا إنترنت يكتشف عند timeout/refresh.
7. غيّر ساعة الجهاز للأمام والخلف: لا تمنح صلاحية خارج الإذن الموقع.
8. مدد الكود ثم أعد التحقق دون تغيير الكود. راجع أن activated_at ثابت.
9. أوقف/ألغ الكود في الإدارة: في التحقق التالي تعود قراءات الموقع وIDFV للأصل وتظهر نافذة الكود.
10. اجعل الكود ينتهي أثناء الاستخدام: لا تظل القيم المحاكية بعد انتهاء الإذن.
11. اختبر IDFV المحفوظ؛ تغيير الهوية لا يغير ارتباط الترخيص.
12. اختبر Keychain بعد إعادة التشغيل وإعادة التوقيع، والتطبيق الثاني، وإعادة الربط.
13. اختبر ثلاث نقرات بإصبع واحد في مساحة فارغة، وبعد تبديل الشاشات والنوافذ والخلفية والمقدمة. تأكد أن النقرات العادية والتمرير وأزرار التطبيق تعمل، وأن النقر المفرد أو المزدوج لا يظهر الأداة.
14. اختبر الخلفية والدوران والكيبورد وإغلاق نافذة الكود واللمس خارجها؛ لا crashes ولا خروج من التطبيق.

لم تُنفذ اختبارات الجهاز أو اتصال سيرفر حقيقي بمجرد نجاح CI. لا تعني هذه القائمة أنها اجتازت بالفعل.
