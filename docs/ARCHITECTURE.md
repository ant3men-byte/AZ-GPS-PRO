# المعمارية
Location/Core.mm يملك إدارة حالة الموقع والحركة والجدولة وطبقة اعتراض الموقع.
UI/UI.mm يملك الواجهة والخريطة والتخصيص ويستدعي واجهات الخدمة.
Identity/Identity.mm يملك اعتراض identifierForVendor وحالة التفعيل المحفوظة.
Audit/Audit.mm يوفر السجل وعارضه.
Shared/Portable.cpp يضم الحسابات المستقلة عن UIKit وCoreLocation.

التقسيم الحالي ينظم الملفات حسب المسؤولية دون إعادة كتابة الكود المجرب.
تقسيم Core.mm وUI.mm إلى وحدات أصغر خطوة لاحقة تتطلب تحققًا على الجهاز، خصوصًا انتقالات الحركة واستعادة الموقع وإعادة ترتيب الأزرار.
