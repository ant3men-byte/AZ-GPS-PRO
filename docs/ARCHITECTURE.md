# المعمارية
Location/Core.mm يدير الموقع الحقيقي والمحاكى الثابت والمحفوظات واعتراضات الموقع.
UI/UI.mm يوفر اللوحة العائمة والخريطة والبحث وأزرار الموقع والمعرف والسجل.
Identity/Identity.mm يدير استبدال identifierForVendor داخل التطبيق.
Audit/Audit.mm يوفر السجل وعارضه.
Shared/Portable.cpp يوفر التحقق من بيانات المواقع المحفوظة.

الزر العائم قابل للسحب بحجم ولون ثابتين. لا تُقرأ إعدادات التخصيص القديمة.
